# Build App Skill

## 适用场景

- 需要围绕一个开发目标产出实现方案。
- 需要生成代码草稿、实施步骤或交付说明。
- 需要在输出中明确依赖、文件变化和验证方式。

## 使用要求

1. 先读取任务上下文和相关文件。
2. 如果需要更多上下文，使用文件读取工具查看已有实现。
3. 输出必须包含：
   - 目标理解
   - 实现步骤
   - 关键文件或模块
   - 验证方式
4. 如果信息不足，明确列出缺失点，不要编造仓库事实。

## 输出风格

- 面向工程实现，保持结构化。
- 优先给出可执行步骤和可验证结论。
