# 需求说明-智能飞行统计报告
这份《需求说明-智能飞行统计报告》文档详细规划了飞行数据统计、智能报告生成、大模型交互及用户偏好记忆等核心功能。以下是整理后的Markdown格式内容：

### 需求说明-智能飞行统计报告

#### 一、产品概述
本功能需集成飞行数据统计、智能报告生成、用户偏好记忆、大模型交互于一体的数据统计服务，核心解决各部门飞行相关数据统计、报告撰写、二次编辑问题等痛点。
需支持常规数据维度、部门维度的周报 / 月报统计，结合智能小助手自然语言对话交互，让用户通过简单指令即可完成筛选条件设置、报告生成、下载编辑等操作，同时通过大模型学习用户报告偏好，持续优化报告生成建议，提升使用效率。

#### 二、核心需求

**2.1 数据统计**

**2.1.1 数据统计模块**
1.  **总体维度**：支持整体飞行统计、算法识别统计、图片（张数 + 时长）统计、视频（数量 + 时长）统计，可按周报、月报、自定义周期（给出时间段格式，汇总数据）。
2.  **部门维度**：根据部门标签（可能多个部门，自动拆分各部门的飞行、算法、成果统计数据，支持各部门独立的周报、月报生成。
3.  **支持周期性数据实时更新**，历史生成的数据后台进行存档。
4.  **数据查询条件筛选**，对部门、数据类型、周期进行筛选。
5.  **飞手数据查询**，支持飞手查询自己的飞行数据，支持管理人员及部门管理人员按一定周期查询飞手的数据。（由于飞手可能隶属一个或多个部门，也可能没有部门，查询飞手飞行数据时会与部门维度数据查询有冲突，使用条件筛选查询时，查询飞手数据时可以根据树状组织架构选取到飞手个人，此时部门维度的查询条件会清空。还需开发确认能否实现，以及飞手数据能支持统计到哪些。）

**2.2 智能报告**

**2.2.1 智能报告模块**
1.  **大模型接入**：接入大模型能力，支持用户通过自然语言选择筛选条件，如“生成农业局10月月报”、“筛选本周总体飞行数据并生成报告”。
2.  **自动生成报告**：根据筛选后的数据， 自动生成报告，包含如数据图表、统计数据、趋势分析、数据同比环比对比等。
3.  **报告格式支持**：输出格式为 docx。
4.  **报告操作**，提供下载，后台存档生成的文档，支持查询。

**2.3 交互需求**

**2.3.1 交互需求模块**
1.  **自然语言对话**：智能小助手支持口语化、自然语言交互，用户无需点击复杂菜单，通过对话即可完成所有操作 (筛选条件设置、报告生成、下载、查询历史报告)。
2.  **进度反馈**：对话过程中同步反馈操作进度、数据概述、报告预览，用户选择操作的流程可视化。
3.  **筛选条件处理**：将自然语言提取的筛选条件， 自动转换为系统可识别的查询参数。支持维度、周期、指标、部门等多条件叠加筛选。

**2.4 个性化需求**

**2.4.1 个性化需求模块**
1.  **偏好记忆**：记录用户每次生成报告的筛选习惯 (如常用周期、关注数据维度、报告侧重点)、记录用户对报告的个性化要求，编辑偏好 (如常用格式、补充内容类型)。
2.  **建议推送**：每个统计周期 (周和月)，智能小助手自动推送报告生成建议，结合当前周期的统计数据推送数据相关建议。

| | | **报告需求记录** | 记录用户对报告的个性化要求，如是否添加图表、是否需要趋势分析、是否隐藏某类指标等 | 后续生成报告可自动应用 |

**2.5 用户权限**

**2.5.1 用户权限模块**
1.  **数据权限**：系统均会实时校验其数据权限，不同用户提供不同的数据权限
2.  **权限变更记录**：用户的权限变更记录到系统日志中。
