# 数据统计模块 API 接口对照表

---

## 一、总体统计

| 三级功能点 | 功能详细说明 | 对应 API 接口 | 状态 |
|---|---|---|---|
| **飞行数据统计** | 支持按周报、月报、自定义周期统计；支持统计飞行次数、飞行总时长、平均时长、最长/最短时长、飞行里程、航线/航点数量、异常告警次数等数据 | `GET /api/device/missions/getFlyStatis` — 飞行统计数据<br>`GET /api/device/flight-task/calendar/overview` — 月度任务统计 | ✅ 有 |
| **算法识别统计** | 支持按给定周期统计；识别总次数、识别目标数量、识别准确率、误识别率、各类目标识别占比等数据 | `GET /api/device/missions/getWarnStatic` — AI数据统计 | ⚠️ 间接匹配 |
| **图片统计** | 按指定周期统计；图片采集总张数、不同场景下的成果图片数量、标注图片数量 | `GET /api/device/missions/getMediaStatic` — 成果统计数据<br>`GET /api/device/achs/storage/stats` — 存储空间使用情况 | ⚠️ 间接匹配 |
| **视频统计** | 按指定周期统计；视频采集总数量、总时长、平均时长等数据 | `GET /api/device/missions/getMediaStatic` — 成果统计数据<br>`GET /api/device/achs/videos` — 获取可用视频列表 | ⚠️ 间接匹配 |

## 二、部门维度统计

| 三级功能点 | 功能详细说明 | 对应 API 接口 | 状态 |
|---|---|---|---|
| **部门数据拆分** | 根据部门标签，自动拆分可追溯到部门标签的飞行、算法识别、图片、视频统计数据，数据指标与总体统计维度完全一致 | — | **无** |
| **部门数据统计** | 支持按周期生成单个部门的全维度统计数据 | — | **无** |
| **部门数据对比** | 支持同周期多部门数据横向对比。对比数据可生成占比等衍生数据，按占比百分比、文字、图表的方式体现 | — | **无** |

> **备注**：现有统计接口（如 `getFlyStatis`、`getMissionStatis` 等）均支持 `deptId` 参数，可按部门筛选，但**无专门的部门数据统计、拆分、对比接口**。

---

## 三、飞手数据查询

| 三级功能点 | 功能详细说明 | 对应 API 接口 | 状态 |
|---|---|---|---|
| **飞手数据统计** | 支持管理人员及部门管理人员按一定周期查询飞手的数据。飞手可以查询自己的飞行数据 | — | **无** |
| **飞手数据对比** | 支持管理人员根据一定周期查询对比多名飞手的数据 | — | **无** |

> **备注**：`GET /api/device/missions/queryByPage` 和 `GET /api/device/missions/getMissionStatis` 支持 `operatorId` / `operatorName` 参数，可按执行人筛选，但**无专门的飞手统计、飞手数据对比接口**。

## 四、周期与数据管理

| 三级功能点 | 功能详细说明 | 对应 API 接口 | 状态 |
|---|---|---|---|
| **数据实时更新** | 周期统计数据随原始数据实时更新，确保数据时效性，无效数据/重复数据不纳入周期统计 | — | **无** |
| **历史数据追溯** | 支持查询任意历史周期（周报/月报/自定义）的存档统计数据，可查看数据原始记录，支持文件导出下载 | `GET /api/device/job/log/list` — 查询飞行历史列表<br>`GET /api/device/job/log/{jobLogId}` — 获取历史记录详情<br>`POST /api/device/job/log/export` — 导出历史数据 | 有 |

## 五、数据查询条件筛选

|---|---|---|---|
| **部门标签筛选** | 用户选择指定的一个部门或多个部门，只可选择用户权限内的部门 | — | **无**（前端通过 `deptId` 参数实现） |

## 六、现有可按部门/飞手筛选的统计接口（补充）

以下接口支持通过 `deptId`、`operatorId`、`beginTime`、`endTime` 等参数实现按部门、按飞手、按时间范围的筛选统计：

| 接口路径 | 方法 | 说明 |
|---|---|---|
| `/api/device/missions/getFlyStatis` | GET | 飞行统计数据 |
| `/api/device/missions/getMissionStatis` | GET | 任务统计数据 |
| `/api/device/missions/getWarnStatic` | GET | AI数据统计 |
| `/api/device/missions/getMediaStatic` | GET | 成果统计数据 |
| `/api/device/missions/getDeviceStatis` | GET | 设备运行统计数据 |
| `/api/device/dashboard/stats/task` | GET | 任务看板｜统计 |
| `/api/device/dashboard/stats/running` | GET | 设备运行｜统计 |
| `/api/device/dashboard/stats/resource` | GET | 资源看板｜统计 |
| `/api/device/dashboard/stats/achievement` | GET | 数据成果｜统计 |
